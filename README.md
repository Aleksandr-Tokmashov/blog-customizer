# Страница блога с возможностью кастомизации
Проект представляет собой блог с возможностью кастомизации его внешнего вида через панель управления. Реализована форма редактирования стилевых свойств блога с передачей данных между компонентами.

## Установка и запуск
- Клонируйте репозиторий: \
`git clone git@github.com:Aleksandr-Tokmashov/blog-customizer.git`
- Установите зависимости: \
`npm install`
- Запустите в development режиме: \
`npm run start`

Для запуска Storybook выполните:

```
npm run storybook
```

Для запуска линтера для стилей выполните:

```
npm run stylelint
```

Для запуска линтера выполните:

```
npm run lint
```

Для запуска форматтера выполните:

```
npm run format
```
